# JavaScript 基礎デモページ

このリポジトリは、Vanilla JS（純粋なJavaScript）を用いたフロントエンドの基本スキル確認用のデモページです。  
イベント操作・DOMの取得・追加・削除・クラス操作・フォーム値の取得・非同期処理（AJAX）など、実務でも頻出する処理を部品ごとにまとめており、学習・復習を目的としています。

📍 デモページ：  
https://fff907.github.io/js-demo/

---

## 🔧 使用技術

- HTML / CSS / JavaScript
- jQuery非使用（Vanilla JSのみ）
- GitHubでバージョン管理

---

## 🛠 主な実装内容

- クリックイベント：ボタンを押すと特定の要素が表示・非表示になる機能
- フォーム操作：フォームから入力された値を取得し、結果を画面に反映
- DOM操作：要素の追加・削除や、HTMLの生成・変更をJavaScriptで実施
- クラス操作：CSSクラスの付け替えで、デザインやアニメーションの切り替えを制御
- 非同期処理：`fetch()` を使って外部JSON（ダミーデータ）を取得し、結果を画面に表示

---

## 📁 ファイル構成（一部抜粋）

- `index.html`：各機能のUIを表示するメインファイル
- `style.css`：ページ全体のスタイル定義
- `main.js`：各機能のJavaScript処理（Vanilla JS）

---

## 💡 本リポジトリの目的

- JavaScriptの基礎文法とDOM操作の定着
- 実務で使う頻度の高い処理（イベント操作、フォーム処理、非同期通信など）を自力で書けるようにする
- GitHub Pagesでの公開体験

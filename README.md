# JavaScript基礎デモページ

このデモページは、Vanilla JavaScript（jQuery不使用）による基本的な処理やイベント制御、DOM操作、非同期通信（AJAX）など、Web開発において頻出する機能を一通り確認・練習する目的で制作しました。

## 🚀 公開URL

[https://fff907.github.io/js-demo/](https://fff907.github.io/js-demo/)

## ✅ 使用技術

- HTML / CSS / JavaScript（Vanilla JS）
- GitHub Pagesによる公開
- GitHubでのバージョン管理

## 🛠 主な実装内容

- **クリックイベント**：ボタンでメッセージを切り替え
- **ループ＋DOM追加**：配列からリスト要素を生成し表示
- **CSSスタイルの変更**：ボタンで文字色などを変更
- **要素の削除**：リストの最後の項目を削除
- **クラスの追加／削除**：スタイルをトグルで切り替え
- **フォーム入力の取得・出力**：ユーザー入力を反映
- **フェードアニメーション**：テキストの表示／非表示をフェードで制御
- **イベントの無効化**：リンクの遷移を無効化し、代わりにメッセージ表示
- **非同期データ取得（AJAX）**：fetchを用いてJSONデータを取得・描画
- **タブ切り替え**：クリックで内容を切り替えるシンプルなタブUI
- **アコーディオン表示**：質問のクリックで回答を開閉
- **モーダルウィンドウ**：画面中央にポップアップ表示／閉じる処理

## 💡 学習ポイント

- JavaScriptの基本構文と制御構造（if文、for文など）
- DOMの取得・生成・削除とイベントリスナーの扱い
- `classList.add()` や `classList.toggle()` を用いたスタイル制御
- `fetch()` による非同期処理の基本理解
- 小規模なUIコンポーネント（タブ／アコーディオン／モーダル）の構築
